# Plan 3-02: FastMCP FinOps Tools Implementation

## Objective
Implement `@mcp.tool()` handlers in `server.py` for `get_client_telemetry(client_id: str)` and `calculate_modernization_tco(current_spend_usd: float, estimated_ai_monthly_queries: int)`, and add the `if __name__ == '__main__': mcp.run(transport='stdio')` execution entrypoint.

## Code Patterns (Model Resilience)
Conventions:
- `@mcp.tool()` decorators with detailed docstrings that Claude Desktop surfaces in tool schemas.
- `get_client_telemetry(client_id: str) -> str`:
  - Strips and uppercases `client_id` for case-insensitive matching.
  - Returns clean markdown table/bullet points with metrics.
  - If client not found, returns list of available client IDs without raising uncaught exception.
- `calculate_modernization_tco(current_spend_usd: float, estimated_ai_monthly_queries: int) -> str`:
  - Input validation: `current_spend_usd >= 0`, `estimated_ai_monthly_queries >= 0`.
  - 30% infra reduction: `infra_savings = current_spend_usd * 0.30`.
  - Claude Haiku tokens:
    - Input: $0.25 / MTok (1,500 tokens/query) -> $0.000375
    - Output: $1.25 / MTok (500 tokens/query) -> $0.000625
    - Total per query = $0.001000
    - Monthly LLM cost = `estimated_ai_monthly_queries * 0.001`
  - Net monthly savings: `infra_savings - monthly_llm_cost`.
  - Formatted audit breakdown with clear financial summary.
- Stdio transport entrypoint: `mcp.run(transport="stdio")`.
