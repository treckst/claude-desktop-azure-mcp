# Plan 3-01: Server Architecture, Azure Blob Client & Fallback Engine

## Objective
Implement `server.py` with FastMCP server initialization, strict stderr logging, Azure Blob Storage client retrieval using `DefaultAzureCredential`, and resilient fallback to an embedded 3-record Pandas DataFrame.

## Code Patterns (Model Resilience)
Conventions:
- Logging: Set up `logging.basicConfig(level=logging.INFO, stream=sys.stderr, format="%(asctime)s [%(levelname)s] %(name)s: %(message)s")`. Never print to stdout.
- Framework: `from mcp.server.fastmcp import FastMCP` -> `mcp = FastMCP("AzureTelemetryBridge")`.
- Azure Client function: `load_telemetry_data() -> pd.DataFrame`.
  - Checks `os.getenv("AZURE_STORAGE_ACCOUNT_NAME")`.
  - If unset or if `BlobServiceClient` / credential fails, catch `Exception`, log warning to `sys.stderr`, and return embedded mock DataFrame:
    - RETAIL-001 (Global Retail Omnichannel)
    - FINTECH-002 (Apex Financial Services)
    - LOGISTICS-003 (Nexus Freight Logistics)
  - Columns: `client_id`, `workload_name`, `industry`, `monthly_db_queries`, `storage_tb`, `current_monthly_spend_usd`, `active_vms`, `estimated_ai_monthly_queries`.
