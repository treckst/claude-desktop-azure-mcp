# Plan 4-02: GitHub Actions CI Automation Workflow

## Objective
Establish an automated CI pipeline in `.github/workflows/ci.yml` that validates code quality, formatting, and unit tests on every push and pull request.

## Code Patterns (Model Resilience)
Conventions:
- Action versions: `actions/checkout@v4`, `actions/setup-python@v5`.
- Python version: 3.11.
- Steps: Checkout -> Setup Python -> Install dependencies (`requirements.txt`) -> `ruff check .` -> `ruff format --check .` -> `pytest -v tests/`.
