# Plan 2-01: Terraform Variables and Client Telemetry Dataset

## Objective
Define the parameterized input variables for the Azure infrastructure and generate the enterprise seed telemetry CSV dataset (`client_telemetry.csv`) representing retail, fintech, and logistics enterprise workloads.

## Code Patterns (Model Resilience)
Conventions:
- In `variables.tf`: Use explicit types (`type = string`), clear descriptions, and production-safe default values.
- In `client_telemetry.csv`: Include standard headers (`client_id,client_name,industry,monthly_cloud_spend_usd,primary_workload,data_volume_gb,active_vms,estimated_ai_monthly_queries`) and 3 realistic enterprise client records (RETAIL-001, FINTECH-002, LOGISTICS-003).
