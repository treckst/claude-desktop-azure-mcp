# Plan 1-01: Enterprise Git Hygiene & Exclusion Rules

## Objective
Establish a comprehensive enterprise-grade `.gitignore` file to ensure secrets, Azure credentials, Terraform state files, Python bytecode, virtual environments, test caches, and OS/IDE metadata are permanently excluded from version control.

## Code Patterns (Model Resilience)
Conventions:
- Group exclusion rules logically under clear section headers: Python, Virtual Environments, Testing & Linting, Terraform, Secrets & Environment, and IDE / OS.
- Add negative patterns (`!`) where appropriate for public examples (e.g., allowing `.env.example`).
- Ensure all paths are relative to repository root.

## Tasks

<task type="auto">
  <name>Create Enterprise .gitignore</name>
  <files>.gitignore</files>
  <action>
    1. Create `.gitignore` in the repository root directory.
    2. Add Python compilation and packaging rules:
       - `__pycache__/`, `*.py[cod]`, `*$py.class`
       - `*.so`, `build/`, `dist/`, `downloads/`, `eggs/`, `.eggs/`, `lib/`, `lib64/`, `parts/`, `sdist/`, `var/`, `wheels/`, `*.egg-info/`
    3. Add Python Virtual Environment rules:
       - `.venv/`, `venv/`, `ENV/`, `env/`, `env.bak/`, `venv.bak/`
    4. Add Testing and Quality Assurance cache rules:
       - `.pytest_cache/`, `.ruff_cache/`, `.coverage`, `htmlcov/`, `.tox/`, `.mypy_cache/`
    5. Add Terraform infrastructure rules:
       - Local runtime cache: `.terraform/`
       - State files: `*.tfstate`, `*.tfstate.*`, `*.tfstate.backup`
       - Crash logs: `crash.log`, `crash.*.log`
       - Overrides: `override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json`
       - Variable definition secrets: `*.tfvars`, `*.tfvars.json`, `terraform.tfvars`, `terraform.tfvars.json`
    6. Add Secrets, Keys, and Environment Variables:
       - Environment files: `.env`, `.env.*`, `!.env.example`
       - Private keys and certs: `*.pem`, `*.key`, `*.pfx`, `*.cert`, `*.cer`
    7. Add IDE, Editor, and OS artifacts:
       - OS files: `.DS_Store`, `Thumbs.db`, `desktop.ini`, `ehthumbs.db`
       - Editor swap files: `*.swp`, `*.swo`, `*~`
       - IDE folders: `.idea/`, `.vscode/*`, `!.vscode/settings.json`, `!.vscode/extensions.json`
  </action>
  <verify>
    powershell -Command "git check-ignore .env terraform/terraform.tfstate .venv/test.py __pycache__/cache.pyc .pytest_cache/v"
  </verify>
  <done>
    `.gitignore` exists at the workspace root and correctly excludes Python artifacts, Terraform state/vars, test caches, and secret credentials.
  </done>
</task>

## Must-Haves
- `.gitignore` exists at repository root.
- Python caches (`__pycache__/`), virtual environments (`.venv/`), and test caches (`.pytest_cache/`, `.ruff_cache/`) are ignored.
- Terraform state files (`*.tfstate`) and variable secrets (`*.tfvars`) are ignored.
- Environment files (`.env`) and private keys are ignored.
